# HIGHGO 담임교사용 데이터 관리 및 수정 가이드

선생님, 안녕하십니까! **HIGHGO**는 학교 정보와 고입 일정을 화면 코드와 완전히 분리하여, 교사가 손쉽게 수정·추가·보완할 수 있도록 설계되었습니다.

---

## 1. 학교 정보 추가 및 수정 (`data/schools.ts`)

새로운 학교를 추가하거나 기존 학교 정보를 수정하려면 `data/schools.ts` 파일을 열어 다음 양식에 맞추어 항목을 편집하시면 됩니다.

```typescript
{
  id: 'sch-new-school',           // 중복되지 않는 고유 ID (영문 소문자)
  name: '○○고등학교',              // 학교명
  category: '전기고' 또는 '후기고',  // 전기/후기 구분
  type: '일반고',                  // 세부 유형 ('과학고', '마이스터고', '특성화고', '일반고', '자율형사립고', '외국어고' 등)
  district: '용산구',              // 서울 25개 자치구 중 하나
  educationOffice: '중부교육지원청', // 관할 교육지원청
  foundation: '공립',             // '공립' 또는 '사립'
  gender: '남녀공학',              // '남녀공학', '남학교', '여학교'
  address: '서울특별시 용산구 ...', // 도로명 주소
  phone: '02-000-0000',           // 입학 상담 대표 번호
  websiteUrl: 'https://...',      // 공식 학교 홈페이지
  admissionUrl: 'https://...',    // 모집요강 페이지 (선택)
  dormitory: false,               // 기숙사 여부 (true / false)
  departments: ['소프트웨어과'],    // 특성화고/마이스터고 모집 학과 목록 (선택)
  description: '...',             // 객관적인 학교 공식 교육 목표 소개 (1~2줄)
  features: ['과학중점', 'AI융합'], // 특색 프로그램 뱃지 (선택)
  tags: ['과학', '공립', '용산구'], // 검색 키워드
}
```

## 2. 고입 전형 및 설명회 일정 수정 (`data/schedules.ts`)

입학설명회 날짜가 확정되거나 교육청 공식 일정이 변경되었을 때 `data/schedules.ts`에서 수정합니다.

```typescript
{
  id: 'evt-2027-new-event',
  title: '○○고등학교 2027 신입생 입학설명회',
  schoolId: 'sch-new-school',       // 특정 학교 일정인 경우 해당 학교의 id 입력 (공통 일정이면 생략)
  schoolName: '○○고등학교',
  category: '입학설명회',             // '입학설명회' | '원서접수' | '서류제출' | '면접실기' | '합격자발표' | '합격자등록' | '중3필수일정'
  targetCategory: '후기고',          // '전기고' | '후기고' | '전체'
  startDate: '2026-10-15',          // 시작일 (YYYY-MM-DD)
  endDate: '2026-10-15',            // 종료일 (YYYY-MM-DD)
  isDDayHighlight: true,            // 메인 홈 D-Day 위젯에 노출할지 여부 (true / false)
  isEssential: false,               // 담임교사 필수 점검 일정 여부 (true 시 강조 표시)
  description: '설명회 장소 및 사전 예약 링크 안내...',
  linkUrl: 'https://...',           // 학교 공지사항 또는 접수처 직접 링크
}
```

## 3. 학급 접근 코드 및 기본 명부 관리 (`data/initialRoster.ts`)

- **교사 코드**: `301`, `302`, `303`, `304` (3학년 1반 ~ 4반)
- **학생 학번**: `30101` ~ `30422` (반별 1번부터 22번까지 기본 등록)
- 명부 범위나 기본 프리셋을 조정하시려면 `data/initialRoster.ts`에서 생성 루프의 학생 번호(`num <= 22`)를 변경하시면 됩니다.

---

## 4. 로컬 스토리지 데이터 초기화

브라우저에서 테스트한 학생 찜 데이터와 상담 메모를 최초 상태로 되돌리고 싶으실 때는:
- `/teacher` 화면 맨 하단의 **[초기 샘플 데이터로 복원]** 버튼을 클릭하시면 즉시 초기화됩니다.
